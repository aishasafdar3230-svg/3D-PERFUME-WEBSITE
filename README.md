# 🌸 3D Perfume Website

A visually immersive perfume showcase website built with **React + Vite**, featuring interactive 3D elements and a fully functional contact form.

🔗 **Live Demo:** https://3-d-perfume-website-iy8e.vercel.app

---

## ✨ Features

- 🎨 Modern, responsive UI design
- 🧴 Interactive 3D perfume showcase
- 📩 Working contact form powered by **Web3Forms**
- ⚡ Built with **React + Vite** for fast performance
- 🚀 Auto-deployed on **Vercel** via GitHub integration

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| React.js | Frontend framework |
| Vite | Build tool & dev server |
| CSS3 | Styling |
| Web3Forms | Contact form email handling |
| Vercel | Hosting & deployment |
