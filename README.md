# 🌸 3D Perfume Website

A visually immersive perfume showcase website built with **React + Vite**, featuring interactive 3D elements and a fully functional contact form.

🔗 **Live Demo:** https://3-d-perfume-website-iy8e.vercel.app

---

## ✨ Features

- 🎨 Modern, responsive UI design
- 🧴 Interactive 3D perfume showcase
- 📩 Working contact form powered by **Web3Forms**
- ⚡ Built with **React + Vite** for fast performance
- 🚀 Auto-deployed on **Vercel** via GitHub integration

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| React.js | Frontend framework |

## 🚀 Getting Started

### Prerequisites
- Node.js installed on your machine
- npm (comes with Node.js)

### Installation

1. Clone the repository
```bash
git clone https://github.com/aishasafdar3230-svg/3D-PERFUME-WEBSITE-.git
```

2. Navigate to the project folder
```bash
cd 3D-PERFUME-WEBSITE-
```

3. Install dependencies
```bash
npm install
```

4. Run the development server
```bash
npm run dev
```

5. Open your browser and go to:
```
http://localhost:5173
```

---

## 📧 Contact Form Setup

This project uses **Web3Forms** for handling contact form submissions.

1. Get your access key from [web3forms.com](https://web3forms.com)
2. Add it in `src/components/Contact.jsx`
3. Submissions will be sent directly to your registered email
